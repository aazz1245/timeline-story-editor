# 故事时间线 Markdown 格式

事件标题使用日期、时段和标题：

```md
### 2030/04/15 上午 - 事件标题
**线路**: 主线
**地点**: 示例地点
**人物**: 角色甲, 角色乙

> 一句话摘要

事件正文

---
```

日期支持 `YYYY/MM/DD` 或 `YYYY-MM-DD`。地点、人物、摘要和正文可以按需填写；人物名单使用逗号分隔。事件之间可用 `---` 分隔。

可选的人物档案以 `#### 人物档案` 开始，每个人物使用 `##### 人物名`，属性采用 `- **属性名**: 属性值`。支持 `身份`（填写 `NPC`）、`内衣款式`、`上衣`、`下装`、`袜饰`、`鞋履`、`笼具`、`特殊饰品`、`胸围`、`罩杯`、`状态` 和 `尺寸`。人物档案会随故事 Markdown 导出，并在再次导入时恢复到事件的人物数据。

Markdown 导入会按标题更新同名事件，并保留其已有 ID 与顺序。没有线路标记的事件默认属于主线；分支章节内未单独标记线路的事件继承章节线路。
