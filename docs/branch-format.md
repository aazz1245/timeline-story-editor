# 分支与分歧点 Markdown 格式

使用二级标题声明分支。分歧点名称可引用主线或其他分支中的事件标题：

```md
## 结局分支: 北线 (分歧点: 事件标题)

### 2030/04/16 下午 - 后续事件
**线路**: 分支:北线
**地点**: 示例地点
**人物**: 角色甲

> 一句话摘要

事件正文
```

同一分支章节中的事件默认归入该分支。`**线路**: 主线` 可将单个事件放回主线；`## 主线` 可结束当前分支章节。

唯一名称的已有分支会被复用，未知名称会新建。分歧点缺失、找不到或标题重复时，事件仍会导入，但暂不建立分歧连接。引用在文件中的位置不影响解析，分歧点会在整批导入后查找。
